# Purchase Vault (Warranty Tracker)

A private, web-first vault for receipts, invoices and warranties. **Save it now. Find it later.**

## Status
Early stage: knowledge base and app skeleton. See `docs/PLAN.md` for the build checklist.

## Docs (start here)
- `CLAUDE.md` — rules for AI/dev contributors
- `docs/SPEC.md` — requirements (source of truth)
- `docs/BUSINESS.md` — vision, personas, business model, risks, roadmap
- `docs/PLAN.md` — architecture and phased plan

## Run locally
```bash
npm install
npm run dev   # http://localhost:3000
```
