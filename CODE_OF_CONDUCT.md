# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

We want this to be a welcoming, harassment-free community for everyone. Be respectful, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, personal attacks, trolling and publishing others' private information are not acceptable.

## Enforcement

Report unacceptable behaviour privately to the maintainer via a [GitHub security advisory](https://github.com/saadamjad/warranty-tracker/security/advisories/new) or by contacting [@saadamjad](https://github.com/saadamjad). All reports will be reviewed promptly and handled confidentially. Maintainers may remove, edit or reject contributions, and temporarily or permanently ban contributors, for behaviour they deem inappropriate.
