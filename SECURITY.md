# Security Policy

This app stores personal purchase records, so we take security and privacy seriously.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/saadamjad/warranty-tracker/security/advisories/new). Include steps to reproduce, the affected version or commit, and the potential impact.

You can expect an acknowledgement within a few days. We will keep you updated on the fix and credit you in the release notes if you wish.

## Supported versions

The project is in early development; only the latest `main` branch is supported.
